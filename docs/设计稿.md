# 《老罗的故事》游戏设计稿 - Design Doc v1.0

> **游戏名：** 老罗的故事  |  **英文名：** Lao Luo's Story
> **类型：** 多分支剧情选择类文字冒险游戏（Visual Novel / Choice-based Adventure）
> **引擎/语言：** Python + Pygame
> **目标平台：** PC端（Windows/macOS/Linux）→ 后续扩展至手机端
> **开发周期：** 第一阶段 3-4 周

---

## 一、核心设计概念

### 1.1 游戏体验目标

| 目标 | 描述 |
|------|------|
| **代入感** | 玩家扮演"老罗"，从负债6亿开始人生抉择 |
| **爽感** | 多个剧情分支体验"逆袭翻红"的快感 |
| **多结局** | 17+种结局，包含隐藏结局 |
| **真实感** | 剧情基于真实创业故事，有共鸣 |

### 1.2 参考游戏

| 参考游戏 | 设计借鉴 |
|---------|---------|
| **逆转裁判 (Phoenix Wright)** | 对话框设计、证据/线索系统、法庭战斗节奏 |
| **命运石之门 (Steins;Gate)** | 多分支时间线、关键抉择点标记、世界线变动率 |
| **Undertale** | 简约像素风、对话气泡动画、角色立绘 |
| **人生重开模拟器** | 选择驱动剧情、属性系统（才华/财富/魅力/心情） |

### 5.2 核心类设计

```python
# GameEngine - 游戏引擎主类
class GameEngine:
    def __init__(self):
        self.screen = None        # Pygame屏幕
        self.clock = None         # 帧率控制
        self.current_screen = None # 当前界面
        self.state = {}           # 全局游戏状态
        self.running = True

    def run(self):
        # 主游戏循环
        while self.running:
            self.handle_events()
            self.update()
            self.draw()

# Scene - 场景类
class Scene:
    def __init__(self, scene_id, background, character, text, choices):
        self.scene_id = scene_id
        self.background = background
        self.character = character
        self.text = text              # 文本列表
        self.choices = choices        # 选项列表

    def is_end_scene(self):
        # 判断是否为结局场景
        return len(self.choices) == 0

# Choice - 选项类
class Choice:
    def __init__(self, text, next_scene, effects=None, hidden=False):
        self.text = text              # 选项文本
        self.next_scene = next_scene  # 下一个场景ID
        self.effects = effects        # 对属性的影响
        self.hidden = hidden          # 是否为隐藏选项

# DialogueBox - 对话框类
class DialogueBox:
    def __init__(self, rect, text, typing_speed=0.05):
        self.rect = rect
        self.full_text = text
        self.display_text = ""
        self.typing_speed = typing_speed
        self.typing_timer = 0
        self.is_complete = False

    def update(self, dt):
        # 逐字显示动画
        if not self.is_complete:
            self.typing_timer += dt
            if self.typing_timer >= self.typing_speed:
                self.typing_timer = 0
                if len(self.display_text) < len(self.full_text):
                    self.display_text += self.full_text[len(self.display_text)]
                else:
                    self.is_complete = True

    def skip_to_end(self):
        self.display_text = self.full_text
        self.is_complete = True

# Ending - 结局类
class Ending:
    def __init__(self, ending_id, title, description, type_, stars, achievement):
        self.ending_id = ending_id
        self.title = title
        self.description = description
        self.type = type_           # "最佳"/"好"/"普通"/"失败"/"隐藏"
        self.stars = stars          # 1-5星
        self.achievement = achievement # 成就名称
```

## 八、素材资源计划

### 8.1 图片素材

**来源1：AI生成**（推荐）
- 使用 Midjourney / Stable Diffusion / DALL-E
- 关键词："Chinese entrepreneur office at night, realistic, dramatic lighting"
- 角色立绘："Middle-aged Chinese man, business suit, serious expression, portrait, anime style"

**来源2：免费素材网站**
- Pexels / Unsplash / Pixabay（免费商业使用）
- itch.io（游戏素材，有免费的）
- 关键词搜索："office background", "live streaming studio"

**来源3：程序生成**（第一阶段替代方案）
- 用渐变+纯色+简单几何图形作为占位背景
- 确保游戏能先跑起来，后续再替换精美素材

### 8.2 音乐素材

**来源1：免费版权音乐**
- [Pixabay Music](https://pixabay.com/music/) - 完全免费
- [Kevin MacLeod (incompetech.com)](https://incompetech.com/) - 免费商用
- YouTube Audio Library - 免费使用

**来源2：AI生成音乐**
- Suno AI / Udio / MusicGen
- 关键词："melancholic piano music for visual novel"

**来源3：程序生成简单音效**
- 用 Python 的 `wave` 库生成简单点击音效
- 第一阶段先用程序合成音效

### 8.3 第一阶段可运行方案

在真正的精美素材到位之前，我们可以用程序生成的占位素材让游戏先跑起来：

```
背景图：
    - 用 Pygame 绘制渐变颜色作为背景
    - 不同场景用不同主色调（办公室=深蓝，直播间=红紫）

角色立绘：
    - 用简单几何图形+文字标签作为角色占位
    - "老罗" = 红色圆形 + "老罗"文字
    - 这样游戏可以先运行，后续再替换精美图

音乐：
    - 第一阶段可以不播放音乐（静音开发）
    - 或者用简单的 pygame.mixer 内置音效
```

## 十、设计原则总结

1. **简约至上** - UI不要太复杂，重点在剧情和选择
2. **爽感第一** - 关键抉择点要有"期待感"
3. **可探索性** - 隐藏结局/隐藏选项带来重复游玩价值
4. **进度可追踪** - 每一个选择都有反馈（状态变化/结局不同）
5. **稳健开发** - 第一阶段能跑起来最重要，后续再美化
