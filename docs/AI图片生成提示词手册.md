## 四、AI图片生成通用参数建议

**分辨率：** 1920x1080（背景）、800x800（角色肖像）
**风格标签：** pixel anime, detailed pixel art, 16-bit style, Chinese visual novel
**色调：** warm tones, dramatic lighting, layered shadow
**附加标签：** no text, no watermark, high quality, game asset

**负面提示词（避免）：**
```
photorealistic, photograph, 3D render, cartoon, anime girl, futuristic,
low quality, blurry, deformed, bad anatomy, watermark, text
```
