# 《罗诚的故事》美术规范 v1

## 整体风格

- **风格定位**：像素风 + 动漫叙事风
- **画面比例**：16:9
- **游戏分辨率**：1280 × 720
- **像素画分辨率**：640 × 360（程序内双线性插值放大）
- **色彩**：低饱和度为主，关键元素用高饱和度点缀
- **情绪基调**：温暖、怀旧、略带感伤，现实故事用童话化方式呈现

## 人物设计

人物采用 **2-4头身 Q版像素人物** 或 **64×64 像素头像**。

| 角色 | 外形特征 |
|------|----------|
| 罗诚（青年） | 长发及肩、倔强眼神、黑色衬衫、偏瘦 |
| 罗诚（中年） | 花白短发、眼袋重、但眼神倔强、常穿深色衬衫 |
| 妻子/林晓 | 短发、温和、浅笑、朴素 |
| 老王 | 微胖、戴眼镜、端着保温杯 |
| 老周 | 瘦高、严肃、西装/正装 |
| 小张 | 马尾、精明、手持计算器/文件夹 |
| 程总 | 深色T恤、笑容、亲和力 |
| 蒂姆 | 外国人、短发、休闲西装、温和 |

## 场景列表

1. `bg_home_old` - 机械厂家属院（红砖楼、黄昏）
2. `bg_room_rent` - 出租屋（小床、单词表墙、台灯）
3. `bg_classroom` - 培训机构教室
4. `bg_office_startup` - 坚石小办公室（拥挤、白板写"工匠"）
5. `bg_factory` - 手机工厂产线
6. `bg_venue` - 发布会场馆
7. `bg_office_night` - 深夜办公室（窗外夜景、电脑屏幕亮）
8. `bg_livestudio` - 直播间（镜头、补光灯、屏幕弹幕）
9. `bg_xiaomi` - 谷米科技园
10. `bg_apple` - 红果园/环形建筑
11. `bg_kitchen` - 家里厨房（温馨、黄昏）
12. `bg_trainstation` - 火车站长椅（夜晚）

## UI 元素

- 对话框：深色半透明底 + 2px 像素边框
- 选择按钮：像素矩形，hover 边框发光
- 属性条：像素图标 + 像素进度条
- 成就弹窗：像素奖杯 + 滑入动画
