# 选题策划案 - 逆袭人生

## 一、游戏定位

**类型：** 多分支剧情模拟游戏（视觉小说式）
**核心玩法：** 玩家扮演真实历史人物，在关键人生节点做出选择，体验从谷底到巅峰（或跌落深渊）的完整人生弧线
**目标用户：** 喜欢剧情向、模拟人生、逆袭爽感的玩家

## 二、核心体验

### 爽感设计
- **起落感**：从负债累累/低谷开局 → 逆袭翻盘
- **选择感**：每个分支都有"命运抉择"的味道
- **重复可玩性**：不同选择解锁不同结局，发现隐藏剧情

### 三、角色故事线规划

#### 角色1：罗永浩（首发）
**起点：** 锤子科技负债6亿，濒临破产
**关键节点：**
1. 继续做手机 vs 转行直播 vs 加入其他公司
2. 如果做手机：高端 vs 低端 vs 卖掉
3. 如果直播：单干 vs 加入机构
4. 如果加入他人：小米 vs 苹果 vs 其他

**结局数量：** 7-9种（含隐藏结局）

---

#### 角色2：俞敏洪（解锁）
**起点：** 新东方被政策打击，濒临倒闭
**关键节点：**
1. 裁员赔偿方案
2. 转型方向：直播带货 vs 素质教育的 vs 其他
3. 东方甄选路线选择

**结局数量：** 5-7种

---

#### 角色3：Elon Musk（解锁）
**起点：** PayPal出售后，濒临破产边缘
**关键节点：**
1. 资金链断裂时：继续烧钱 vs 收缩
2. 特斯拉Model X发布：定价策略
3. SpaceX火箭连续失败：放弃 vs 继续

**结局数量：** 6-8种

---

## 四、分支结构示例（罗永浩线）

```
【第一幕：至暗时刻】
锤子科技资金链断裂，债主上门
→ 你会怎么做？

├─ A. 继续死磕手机行业
│     ├─ A1. 坚持高端路线 → 资金耗尽，公司倒闭
│     ├─ A2. 转型做性价比 → 勉强维持，疲惫不堪
│     └─ A3. 卖掉公司给字节跳动 → ★触发新剧情
│
├─ B. 转型直播带货
│     ├─ B1. 自己单干 → 初期被嘲笑，后翻红 ★
│     └─ B2. 加入MCN机构 → 被坑，收入被抽成
│
├─ C. 加入小米（雷军邀请）
│     ├─ C1. 负责高端手机项目 → 理念冲突，黯然离开
│     └─ C2. 做中低端产品线 → 还清债务，但失去自由
│
├─ D. 加入苹果（库克邀请）
│     └─ D1. 从产品顾问做起 → 隐藏结局线
│
└─ E. 卖掉公司，彻底退出
      └─ → 平淡结局，但你解锁了"平凡人生"奖章
```

## 五、结局分类

| 结局类型 | 描述 | 爽感指数 |
|---------|------|---------|
| 巅峰结局 | 逆袭成功，身家翻倍 | ★★★★★ |
| 翻红结局 | 绝地反击，小有成就 | ★★★★ |
| 平淡结局 | 功成身退，岁月静好 | ★★★ |
| 失败结局 | 债务缠身，艰难维生 | ★★ |
| 隐藏结局 | 意想不到的人生 | ★★★★★ |

## 六、解锁机制

- 通关罗永浩任意结局 → 解锁俞敏洪
- 通关俞敏洪任意结局 → 解锁Elon Musk
- 集齐3个巅峰结局 → 解锁"传奇人生"隐藏章节
- 特定选择组合 → 解锁隐藏角色
