GAME INTRODUCTION

游戏简介

◆

基于真实人物改编的互动叙事游戏，每一个选择都有重量

🌳

六幕式叙事结构

少年时代 → 北漂岁月 → 坚石时代 → 至暗时刻 → 重生之路 → 终章。像追一部好剧一样推进剧情，每幕有悬念、有高潮、有情感炸弹。

⚖️

三维数值系统

理想值代表对梦想的坚持，现实值代表对商业的妥协，温情值代表对家人朋友的珍视。每个选择都会改变属性，属性导向不同结局。

🔓

多周目解锁设计

第一次玩看不到D支线，通关一次后解锁隐藏路线。E支线仅一周目可见，类似《尼尔：机械纪元》的多周目叙事设计。

STORY ARCHITECTURE

剧情架构

◆

六幕式叙事，约5万字剧本，87个精心设计的场景

第一幕 · 少年时代

机械厂家属院的童年，父亲修收音机的背影，课堂上的"自由宣言"，退学离家的那个夜晚，火车站长椅上的星空，二手书店遇到的人生导师，摆地摊被城管追的狼狈。

第二幕 · 北漂岁月

出租屋闭关背单词，三千遍录音的疯狂，求职信石沉大海，第一堂课的紧张与兴奋，遇见生命中的她，博客时代的风起云涌，罗诚英语的成名之路，"做手机"的邀约到来。

第三幕 · 坚石时代

三十人挤在走廊创业，第一台原型机的诞生，S1发布会的震撼，第一家线下店的热闹，代工厂的深夜危机，供应商酒桌上的妥协，最后一次团建的欢笑与隐忧。

第四幕 · 至暗时刻

深夜办公室的老照片，妻子深夜的来电，走廊尽头的那根烟，老王来告别的那个下午，老周说"不管你做什么我跟着"，五条路摆在面前——你选哪一条？

第五幕 · 重生之路

每条支线都有3-5个中间选择点：A线继续做手机面临降本提价的抉择，B线直播从被骂到走红的蜕变，C线谷米从被否到Note大卖，D线红果的文化冲击，E线退出后的平凡生活。

第六幕 · 终章

13种结局，从"理想不死"到"细红线归来"，每个结局都有"多年以后"的尾声。多年后的你，会如何回望当年那个站在十字路口的自己？

CORE FEATURES

核心特色

◆
🎨

像素+动漫美学

清新像素风与沉重现实题材形成艺术反差，类似《去月球》《拣爱》的"童话画风讲深刻故事"，用温暖的画面包裹每一个至暗时刻。

🎭

有血有肉的角色

老王、老周、小张、妻子林晓、程总、蒂姆……每个配角都有自己的故事线，不只是推动剧情的工具人。他们的选择，也在影响着你。

🏆

成就收集系统

17个可解锁成就，从"初出茅庐"到"理想不死"，从"真还传说"到"细红线归来"，鼓励多周目探索，每一次游玩都有新发现。

🎵

沉浸式音乐体验

6种场景背景音乐，主菜单、剧情、温情、紧张、结局、庆祝，随剧情自动切换，配合场景氛围，让每一次抉择都更有代入感。

⌨️

键鼠双操控

支持键盘数字键/方向键/空格键快速操作，也支持鼠标点击选择。自动存档+手动存档，随时退出，随时继续，不让进度丢失。

📱

多平台适配

PC端（Windows/Mac）首发，后续适配手机端。Python + Pygame 开发，轻量高效，低配电脑也能流畅运行。

ATTRIBUTE SYSTEM

三维属性系统

◆

你的每一个选择，都在塑造你是谁

🔥
理想值

对梦想的坚持，对产品的执念。越高越容易走理想主义路线，可能成功也可能撞得头破血流。

💼
现实值

对商业的理解，对现实的妥协。越高越容易做出"正确"的商业决策，但可能会失去一些东西。

❤️
温情值

对家人朋友的珍视，对身边人的温度。越高越能收获真挚的情感，在低谷时也有人愿意陪你走。
